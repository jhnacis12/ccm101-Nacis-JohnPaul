# Laboratory 04 - Cloud-Native Engineer

## Mission Overview

This activity introduces Docker and containerization.

## Objectives

* Learn the difference between VMs and containers.
* Use Docker in KillerCoda.
* Run an Nginx container.
* Manage a Docker container.

## Docker Commands

```bash
docker --version
docker info
docker pull nginx
docker run -d --name my-nginx -p 8080:80 nginx
curl http://localhost:8080
docker ps
docker stop my-nginx
docker ps
docker rm my-nginx
```
